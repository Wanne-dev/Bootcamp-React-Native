# Semana 11: APIs Nativas

- Ruta: `bootcamp/week-11-apis-nativas/`
- Dominio de práctica: Papelería Digital (escaner de códigos y ubicación de la tienda)

## Descripción

Se integran capacidades del dispositivo: escaner de códigos de barras para verificar productos y ubicación para mostrar la tienda, con manejo de permisos.

## Objetivos

- Usar la camara para escanear códigos.
- Obtener y mostrar la ubicación de la tienda.
- Manejar permisos de forma correcta.

## Entregables

1. Pantalla de escaneo que reconoce el código de un producto.
2. Pantalla con la ubicación de la tienda.

## Contenido de la semana

| Carpeta | Contenido |
|---|---|
| `1-teoria/` | Camara y escaner, ubicación y permisos |
| `2-practicas/` | Escanear código y mostrar ubicación |
| `3-proyecto/` | Validar producto por código |
| `4-recursos/` | Documentación de Expo |
| `5-glosario/` | Términos clave |

## Checklist de entrega

- [ ] El escaner reconoce un código y muestra el producto.
- [ ] La pantalla de ubicación muestra la tienda.
- [ ] Los permisos se solicitan y se manejan sus rechazos.
- [ ] La camara y la ubicación se liberan al salir de la pantalla.
