# Glosario - Semana 11

| Término | Definición |
|---|---|
| API nativa | Capacidad del dispositivo accesible desde la app (camara, ubicación) |
| expo-camera | Módulo de Expo para usar la camara y escanear códigos |
| expo-location | Módulo de Expo para obtener la ubicación del dispositivo |
| Permiso | Autorización del usuario para usar una capacidad del dispositivo |
| Código de barras | Representacion visual de datos que la camara puede leer |
| SKU | Código único del producto que el escaner puede buscar |
| Barcode | Código de barras reconocible por la camara |
| Latitud | Coordenada geografica norte-sur |
| Longitud | Coordenada geografica este-oeste |
| Georreferencia | Par latitud-longitud que ubica un punto en el mapa |
| deep link | Enlace que abre una aplicación o servicio externo (Google Maps) |
| GPS | Sistema de posicionamiento global del dispositivo |
