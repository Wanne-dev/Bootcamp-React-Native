# Proyecto Semana 11 - Validar producto por código

## Objetivo

Integrar el escaner y la ubicación en la app de la papelería.

## Estructura de archivos

```text
HolaMundo/
|-- src/
|   |-- screens/
|   |   |-- EscanerScreen.jsx     // camara + SKU
|   |   |-- TiendaScreen.jsx       // ubicacion + ruta
|   |-- navigation/
|   |   |-- RootNavigator.jsx      // nuevas rutas
```

## Criterios de éxito

- [ ] Se puede escanear un producto y ver su detalle.
- [ ] La pantalla de tienda muestra dirección y abre la ruta.
- [ ] Los permisos se manejan con mensajes claros.
- [ ] La camara y la ubicación se liberan al salir.
