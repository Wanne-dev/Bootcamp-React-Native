# Semana 10: Reanimated y Gestos

- Ruta: `bootcamp/week-10-reanimated-gestos/`
- Dominio de práctica: Papelería Digital (gestos en el carrito)

## Descripción

Se reemplazan las animaciones basicas por React Native Reanimated y se agregan gestos con Gesture Handler, como deslizar un producto del carrito para eliminarlo.

## Objetivos

- Configurar Reanimated y Gesture Handler.
- Crear animaciones fluidas con `useSharedValue` y `withTiming`.
- Usar `GestureDetector` para gestos de swipe.
- Aplicar el gesto de deslizar para quitar del carrito.

## Entregables

1. Carrito con gesto de deslizar para eliminar productos.
2. Animaciones fluidas en botones y tarjetas.
