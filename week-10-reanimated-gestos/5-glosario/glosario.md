# Glosario - Semana 10

| Término | Definición |
|---|---|
| Reanimated | Librería de animaciones de React Native que corre en el hilo de UI |
| Worklet | Función que se ejecuta en el hilo de UI |
| useSharedValue | Hook que crea un valor compartido animable |
| withTiming | Función que anima un valor con una duración fija |
| withSpring | Función que anima un valor con física de resorte |
| useAnimatedStyle | Hook que declara estilos dependientes de valores compartidos |
| Gesture Handler | Librería de gestos de React Native |
| GestureDetector | Componente que detecta y gestiona un gesto |
| Gesture.Pan | Gesto de arrastre en cualquier dirección |
| GestureHandlerRootView | Contenedor raiz requerido por Gesture Handler |
| translationX | Desplazamiento horizontal de un gesto |
| Umbral (threshold) | Límite que define cuando un gesto se considera válido |
| Swipe to delete | Patron de deslizar para eliminar un elemento |
