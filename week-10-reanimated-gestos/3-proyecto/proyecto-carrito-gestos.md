# Proyecto Semana 10 - Carrito con gestos

## Objetivo

Integrar Reanimated y Gesture Handler en el carrito de la papelería.

## Estructura de archivos

```text
HolaMundo/
|-- App.js                       // GestureHandlerRootView + Navigation
|-- babel.config.js              // plugin de worklets
|-- src/
|   |-- components/
|   |   |-- LineaCarrito.jsx     // swipe para eliminar
|   |-- stores/
|   |   |-- carritoStore.js
|   |-- screens/
|   |   |-- CarritoScreen.jsx
```

## Criterios de éxito

- [ ] Swipe horizontal elimina productos con animación.
- [ ] El scroll vertical de la lista funciona normal.
- [ ] Las animaciones son fluidas.
- [ ] El carrito persistente de semanas anteriores sigue funcionando.
