# Glosario - Semana 15

| Término | Definición |
|---|---|
| EAS | Expo Application Services: servicios en la nube de Expo |
| EAS Build | Servicio de compilación de apps en la nube |
| eas-cli | Herramienta de línea de comandos de EAS |
| eas.json | Archivo de configuración de perfiles de build y submit |
| app.json | Archivo de configuración principal de la app |
| Perfil de build | Conjunto de opciones para un tipo de compilación |
| APK | Paquete instalable de Android |
| AAB | Android App Bundle: formato para Google Play |
| IPA | Paquete de la app para iOS |
| Firmado | Firma digital que identifica y valida la app |
| package | Identificador único de la app en Android |
| bundleIdentifier | Identificador único de la app en iOS |
| Development Client | Build de desarrollo con soporte de depuración |
| artefacto | Archivo resultante de una compilación |
