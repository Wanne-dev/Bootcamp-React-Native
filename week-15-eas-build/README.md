# Semana 15: EAS Build

- Ruta: `bootcamp/week-15-eas-build/`
- Dominio de práctica: Papelería Digital (compilar la app)

## Descripción

Se compila la aplicación en la nube con EAS Build, generando artefactos instalables (APK o AAB) sin necesidad de Android Studio o Xcode local.

## Objetivos

- Configurar un proyecto para EAS (`eas.json`, `app.json`).
- Lanzar un build exitoso.
- Entender los perfiles de build.

## Entregables

1. Archivo `eas.json` configurado.
2. Build completado y artefacto descargado.
