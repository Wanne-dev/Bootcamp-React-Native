# Proyecto Semana 15 - Build de producción

## Objetivo

Compilar el AAB de producción de Papelería Digital, listo para subir a Google Play.

## Entregables

1. `eas.json` con los perfiles.
2. AAB de producción compilado.
3. Captura del build en verde y del artefacto.

## Criterios de éxito

- [ ] El AAB existe y se descargo.
- [ ] El identificador y la versión están definidos.
- [ ] Los iconos y el splash no usan valores por defecto.
- [ ] El build se documenta en el repositorio.
