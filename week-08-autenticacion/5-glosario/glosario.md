# Glosario - Semana 08

| Término | Definición |
|---|---|
| Autenticación | Proceso de verificar la identidad de un usuario |
| Login | Inicio de sesión con credenciales |
| Credenciales | Correo y contraseña que identifican al usuario |
| Token | Texto emitido por el servidor que representa la sesión |
| JWT | JSON Web Token: token firmado con datos del usuario |
| SecureStore | Almacenamiento cifrado de Expo para datos sensibles |
| Sesión | Periodo en que el usuario permanece autenticado |
| Ruta protegida | Pantalla que exige sesión iniciada |
| Cierre de sesión | Acción que termina la sesión y elimina el token |
| Keychain | Almacenamiento seguro de iOS |
| Keystore | Almacenamiento seguro de Android |
| Header de autorización | Cabecera HTTP que envía el token en las peticiones |
