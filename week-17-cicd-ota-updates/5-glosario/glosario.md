# Glosario - Semana 17

| Término | Definición |
|---|---|
| CI | Integración continua: pruebas automaticas en cada cambio |
| CD | Entrega/despliegue continuo: automatizar la publicación |
| Pipeline | Secuencia de pasos automatizados del repositorio |
| GitHub Actions | Servicio de automatización de GitHub |
| Workflow | Definición de un pipeline en un archivo YAML |
| Job | Tarea del workflow que corre en un runner |
| Step | Paso individual dentro de un job |
| Runner | Maquina virtual que ejecuta los jobs |
| push | Evento que dispara el workflow al subir cambios |
| pull request | Evento que dispara el workflow al proponer cambios |
| OTA | Over The Air: actualización entregada por la red |
| EAS Update | Servicio de Expo para publicar actualizaciones OTA |
| runtimeVersion | Versión del código JS que define compatibilidad de updates |
| Branch (update) | Canal de distribución de las actualizaciones |
| Artifacto | Archivo resultante de una compilación o proceso |
