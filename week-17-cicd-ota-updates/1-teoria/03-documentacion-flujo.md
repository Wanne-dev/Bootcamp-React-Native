# 03 - Documentación del flujo

## Objetivos de aprendizaje

- Documentar el pipeline para el equipo y para entregar.

## 1. Qué documentar

- Comandos de instalación, test y build.
- Cómo se despliega una actualización OTA.
- Cuando se requiere build nuevo frente a update.

## 2. Tabla de referencia para el README

| Cambio | Via |
|---|---|
| Corregir textos o lógica JS | `eas update` |
| Agregar un módulo nativo | `eas build` + tienda |
| Cambiar permisos | `eas build` + tienda |

## 3. Regla

El README del repositorio debe permitir a una persona nueva ejecutar el pipeline completo sin preguntar.
