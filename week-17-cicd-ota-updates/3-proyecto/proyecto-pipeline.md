# Proyecto Semana 17 - Pipeline del repositorio

## Objetivo

Cerrar la automatización del repositorio: CI con tests en cada push y despliegue de actualizaciones OTA.

## Entregables

1. Workflow de CI funcionando en el repositorio.
2. Configuración de EAS Update en el proyecto.
3. Documento `flujo-despliegue.md` con comandos y casos de uso.

## Criterios de éxito

- [ ] El pipeline corre los tests y verifica tipos en cada push.
- [ ] La actualización OTA llega a la app instalada.
- [ ] El flujo completo está documentado.
- [ ] El equipo (o el evaluador) puede reproducir el proceso.

## Cierre del track

Con el pipeline listo, el track técnico queda completo: componentes, navegación, estado, datos, persistencia, autenticación, animaciones, nativas, testing, rendimiento, build, publicación y automatización.
