# Glosario - Semana 07

| Término | Definición |
|---|---|
| Persistencia | Capacidad de conservar datos entre sesiones de la aplicación |
| AsyncStorage | Almacenamiento local clave-valor asíncrono de React Native |
| Clave (storage) | Nombre único que identifica un dato guardado |
| Prefijo de clave | Texto inicial comun del proyecto en todas las claves |
| `setItem` | Método para guardar un valor en el almacenamiento |
| `getItem` | Método para leer un valor del almacenamiento |
| `removeItem` | Método para eliminar una clave |
| `clear` | Método para borrar todo el almacenamiento |
| `JSON.stringify` | Convierte un objeto a texto para poder guardarlo |
| `JSON.parse` | Convierte texto guardado de vuelta a objeto |
| Hidratación | Restauracion del estado desde el almacenamiento al iniciar |
| Valor por defecto | Resultado que se devuelve cuando no hay nada guardado o hay error |
| Favorito | Producto marcado por el usuario para encontrarlo rápido |
| Preferencia | Ajuste del usuario (moneda, categoría principal) |
