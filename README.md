# Bootcamp de Desarrollo Movil: Digitalizacion de una Papeleria

Programa practico de 5 semanas para construir una aplicacion movil de catalogo, inventario y pedidos para una papeleria, usando React Native y Expo.

## Estructura del programa

| Semana | Tema | Objetivo principal |
|---|---|---|
| 00 | Fundamentos y Estrategia | Definir el modelo de negocio, el publico objetivo y configurar el entorno de desarrollo |
| 01 | Catalogo e Inventario | Modelar el catalogo de productos y su disponibilidad |
| 02 | Diseno UI/UX | Definir la interfaz y la experiencia de usuario de la aplicacion |
| 03 | Carrito y Busqueda | Implementar busqueda y gestion de pedidos en la app |
| 04 | Pagos y Pedidos | Cerrar el flujo de compra y entrega del pedido |

## Convenciones del repositorio

Cada semana sigue la misma estructura interna:

```text

|-- README.md              Descripcion y entregables de la semana

|-- 1-teoria/              Material conceptual
|-- 2-practicas/           Ejercicios guiados
|-- 3-proyecto/            Proyecto de la semana
|-- 4-recursos/            Enlaces y material complementario

```
