# Glosario - Semana 03

| Término | Definición |
|---|---|
| Navegación | Cambio entre pantallas de una aplicación |
| React Navigation | Librería de navegación para React Native |
| NavigationContainer | Componente raiz que envuelve toda la navegación de la app |
| Navigator | Componente que gestiona un conjunto de pantallas (Stack o Tab) |
| Stack Navigator | Pila de pantallas donde cada nueva se apila sobre la anterior |
| Native Stack | Stack que usa primitivas nativas de cada plataforma |
| Tab Navigator | Navegación por pestanas inferiores |
| Screen | Pantalla registrada dentro de un Navigator |
| Ruta (route) | Entrada del navegador que identifica una pantalla y sus parámetros |
| Parámetro | Dato que se envía de una pantalla a otra al navegar |
| `navigation.navigate` | Método para ir a otra pantalla |
| `route.params` | Objeto con los parámetros recibidos en la pantalla destino |
| Cabecera (header) | Barra superior con título y flecha de volver |
| Pestana (tab) | Botón inferior que cambia entre secciones principales |
| Anidar | Colocar un Navigator dentro de otro (un Stack dentro de un Tab) |
