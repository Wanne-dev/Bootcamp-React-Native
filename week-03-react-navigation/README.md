# Semana 03: React Navigation

- Ruta: `bootcamp/week-03-react-navigation/`
- Dominio de práctica: Papelería Digital

## Descripción

Se conectan las pantallas de la aplicación con navegación: una pestaña con el catálogo y el carrito, y una pila para ir del catálogo al detalle de cada producto.

## Objetivos

- Instalar y configurar React Navigation.
- Crear un Stack Navigator (Catálogo → Detalle de Producto).
- Crear un Tab Navigator (Catálogo y Carrito).
- Pasar parámetros entre pantallas.

## Entregables

1. App con navegación funcional entre Home, Detalle de Producto y Carrito.
2. El detalle recibe el producto seleccionado por parámetro.

## Checklist de entrega

- [ ] Al tocar un producto se abre su detalle.
- [ ] El detalle recibe el producto por parámetro.
- [ ] La app tiene pestanas Catálogo y Carrito.
- [ ] La navegación no pierde la barra inferior al entrar al detalle.
