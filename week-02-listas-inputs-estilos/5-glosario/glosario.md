# Glosario - Semana 02

| Término | Definición |
|---|---|
| Estado local | Valor gestionado por un componente con `useState` |
| TextInput | Componente de entrada de texto en React Native |
| Campo controlado | Input cuyo valor proviene del estado y se actualiza con `onChangeText` |
| Filtro | Conjunto de resultados obtenidos al aplicar una condición sobre un arreglo |
| `filter()` | Método de arreglos que devuelve los elementos que cumplen una condición |
| `includes()` | Método de cadenas que indica si contiene un texto dado |
| Normalizar | Llevar un texto a minúsculas u otra forma para compararlo sin ambiguedad |
| Clave (`key`) | Identificador único y estable de cada elemento de una lista |
| keyExtractor | Propiedad de FlatList que devuelve la clave de cada elemento |
| Categoría | Clasificación del catálogo: escolar, oficina, arte, tecnología |
| Chip | Elemento de interfaz pequeño y redondeado que representa una opción |
| Tema | Conjunto centralizado de colores, espaciados y radios de la app |
| Token de diseño | Valor reutilizable del tema (un color o un espaciado con nombre) |
| Estado vacío | Mensaje que se muestra cuando una lista no tiene resultados |
