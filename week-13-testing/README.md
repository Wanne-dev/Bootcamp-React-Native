# Semana 13: Testing

- Ruta: `bootcamp/week-13-testing/`
- Dominio de práctica: Papelería Digital (pruebas del carrito y componentes)

## Descripción

Se escriben pruebas automatizadas para los componentes y la lógica de la aplicación: la tarjeta de producto, el buscador y el store del carrito.

## Objetivos

- Configurar Jest y React Native Testing Library.
- Escribir pruebas unitarias de componentes.
- Probar la lógica del store del carrito.
- Usar mocks correctamente.

## Entregables

1. Suite de pruebas del componente TarjetaProducto.
2. Suite de pruebas del store del carrito.

## Checklist de entrega

- [ ] Los tests se ejecutan con `npm test`.
- [ ] La tarjeta renderiza nombre y precio.
- [ ] El buscador filtra el arreglo correctamente.
- [ ] Las acciones del carrito se prueban por separado.
