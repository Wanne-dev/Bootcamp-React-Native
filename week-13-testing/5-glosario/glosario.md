# Glosario - Semana 13

| Término | Definición |
|---|---|
| Test | Prueba automatizada que verifica un comportamiento |
| Test unitario | Prueba de una unidad aislada (función o componente) |
| Jest | Framework de pruebas de JavaScript |
| jest-expo | Preset de Jest para proyectos Expo |
| React Native Testing Library | Librería para probar componentes de React Native |
| render | Función que monta un componente para probarlo |
| query | Función que busca elementos en el componente renderizado |
| getByText | Query que busca un elemento por su texto |
| beforeEach | Función que se ejecuta antes de cada test |
| Mock | Doble que reemplaza una dependencia en las pruebas |
| jest.mock | Función que declara un mock de un módulo |
| Determinista | Prueba que da el mismo resultado siempre |
| Sujeto de prueba | Pieza de código que se está probando |
| Función pura | Función que no tiene efectos secundarios y es fácil de probar |
| Suite | Conjunto de tests de un mismo módulo |
| Cobertura | Porcentaje del código ejercitado por las pruebas |
