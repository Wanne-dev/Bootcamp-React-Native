# Glosario - Semana 01

| Término | Definición |
|---|---|
| Componente core | Elemento básico de interfaz de React Native: View, Text, Image, ScrollView, FlatList |
| View | Contenedor básico equivalente a un div; agrupa componentes y aplica estilos de caja |
| Text | Componente para mostrar texto; todo texto de la app debe ir dentro de el |
| Image | Componente para mostrar imágenes locales o remotas |
| ScrollView | Contenedor desplazable para contenido largo |
| FlatList | Lista optimizada que renderiza solo los elementos visibles |
| flexbox | Sistema de layout para distribuir y alinear elementos en ejes |
| flexDirection | Propiedad que define la dirección del eje principal (row o column) |
| justifyContent | Distribución de los elementos en el eje principal |
| alignItems | Alineacion de los elementos en el eje secundario |
| flex | Propiedad que indica cuánto crece un elemento para ocupar espacio |
| dp | Density-independent pixel: unidad de medida de React Native |
| StyleSheet | Objeto que agrupa y valida los estilos de un componente |
| SKU | Código único que identifica cada producto; se usa como clave en la FlatList |
| prop | Propiedad que recibe un componente para configurarlo con datos |
| renderItem | Propiedad de FlatList que define cómo se dibuja cada elemento |
| keyExtractor | Propiedad de FlatList que devuelve la clave única de cada elemento |
