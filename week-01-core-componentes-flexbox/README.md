# Semana 01: Componentes Core y Flexbox

- Ruta: `bootcamp/week-01-core-componentes-flexbox/`
- Dominio de práctica: Papelería Digital (catálogo de la papelería)

## Descripción

Primeras pantallas de la aplicación usando los componentes core de React Native y el sistema de layout flexbox. Se maqueta la pantalla Home del catálogo con la lista de productos de la papelería.

## Objetivos

- Usar los componentes core: `View`, `Text`, `Image`, `ScrollView` y `FlatList`.
- Construir layouts con flexbox: `flexDirection`, `justifyContent`, `alignItems` y `flex`.
- Organizar los estilos con `StyleSheet`.

## Entregables

1. Pantalla Home maquetada que lista el catálogo de productos.
2. Componente Tarjeta de Producto construido con flexbox.
