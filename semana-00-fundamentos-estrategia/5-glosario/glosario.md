# Glosario - Semana 00

| Termino | Definicion |
|---|---|
| MVP | Producto Minimo Viable: version inicial de la aplicacion con las funciones minimas necesarias para validar la idea con usuarios reales con el menor esfuerzo posible |
| B2B | Business to Business: modelo donde la empresa vende a otras empresas, por ejemplo una papeleria que atiende oficinas |
| B2C | Business to Consumer: modelo donde la empresa vende directamente al consumidor final, por ejemplo estudiantes o padres de familia |
| Expo | Plataforma de herramientas sobre React Native que acelera el desarrollo de aplicaciones moviles (Expo Go, compilacion y servicios en la nube) |
| Expo Go | Aplicacion movil que permite ejecutar y visualizar proyectos de Expo directamente en el telefono sin compilar |
| React Native | Framework basado en JavaScript y React para crear aplicaciones moviles nativas para iOS y Android desde un mismo codigo |
| Node.js | Entorno de ejecucion de JavaScript fuera del navegador; requerido por las herramientas de desarrollo |
| npm | Gestor de paquetes de Node.js; instala dependencias y ejecuta tareas del proyecto |
| npx | Comando que ejecuta paquetes de npm sin necesidad de instalarlos de forma global |
| Git | Sistema de control de versiones distribuido para registrar los cambios del proyecto |
| Repositorio | Espacio, local o remoto en GitHub, donde se almacena y versiona el codigo del proyecto |
| Commit | Registro puntual de un conjunto de cambios en el historial de Git |
| Push | Accion de enviar los commits del repositorio local al repositorio remoto |
| Rama (branch) | Linea independiente de desarrollo; la rama principal se suele llamar `main` |
| Entorno de desarrollo | Conjunto de herramientas instaladas y configuradas para programar (Node, Expo, VS Code, Git) |
| Hot reload | Actualizacion automatica de la aplicacion en el dispositivo al guardar cambios en el codigo |
| MoSCoW | Tecnica de priorizacion que clasifica funciones en Must, Should, Could y Won't |
| Emulador | Software que simula un dispositivo movil en la computadora para probar la aplicacion |
