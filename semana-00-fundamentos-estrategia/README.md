# Semana 00: Fundamentos y Estrategia

- Ruta: `bootcamp/semana-00-fundamentos-estrategia/`
- Proyecto: Digitalizacion de una papeleria
- Nombre de trabajo de la app: `Papeleria Digital`

## Descripcion

Introduccion al proyecto de digitalizacion de la papeleria. En esta semana no se desarrolla codigo de producto: se establece la base estrategica del proyecto (modelo de negocio y publico objetivo) y se deja el entorno de desarrollo configurado para las siguientes semanas.

## Objetivos

- Definir el modelo de negocio de la aplicacion.
- Definir el publico objetivo (escolar, oficina, arte).
- Configurar el entorno de desarrollo (Node.js, Expo, Git y VS Code).

## Entregables

1. Documento de estrategia con la vision del negocio digital (`3-proyecto/proyecto-estrategia.md`).
2. Entorno de desarrollo funcionando: proyecto "Hola Mundo" ejecutandose con Expo (`2-practicas/practica-01-instalacion-expo.md`).
