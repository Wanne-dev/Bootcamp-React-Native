# Glosario - Semana 14

| Término | Definición |
|---|---|
| Rendimiento | Capacidad de la app de responder fluida ante el usuario |
| Virtualizacion | Técnica de FlatList de renderizar solo los elementos visibles |
| removeClippedSubviews | Prop que recorta vistas fuera de pantalla |
| initialNumToRender | Elementos renderizados al inicio de la lista |
| maxToRenderPerBatch | Elementos renderizados por lote |
| windowSize | Tamanio de la ventana de renderizado de la lista |
| getItemLayout | Declaracion de la altura fija de cada elemento |
| Memoización | Técnica para evitar recalculos o renderizados repetidos |
| React.memo | Función que evita re-renderizar si las props no cambian |
| useMemo | Hook que memoriza un valor calculado |
| useCallback | Hook que memoriza una función |
| Renderizado | Proceso de construir la interfaz de un componente |
| FPS | Fotogramas por segundo; 60 fps se percibe fluido |
| Profiler | Herramienta para medir renderizados en React |
