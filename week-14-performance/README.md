# Semana 14: Performance

- Ruta: `bootcamp/week-14-performance/`
- Dominio de práctica: Papelería Digital (catálogo a escala)

## Descripción

Se optimiza el catálogo para que funcione fluido con cientos o miles de productos: listas optimizadas, memoización y medición.

## Objetivos

- Optimizar FlatList (windowSize, getItemLayout, removeClippedSubviews).
- Aplicar memoización con React.memo, useMemo y useCallback.
- Medir el rendimiento antes y después.

## Entregables

1. Catálogo con 1000 productos renderizado fluido.
2. Documento con la medición del antes y el después.
