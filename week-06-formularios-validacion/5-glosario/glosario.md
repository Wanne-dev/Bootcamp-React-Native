# Glosario - Semana 06

| Término | Definición |
|---|---|
| Formulario | Conjunto de campos que recopilan datos del usuario |
| React Hook Form | Librería de formularios por rendimiento y sin re-renderizados extra |
| useForm | Hook principal de React Hook Form |
| control | Objeto que gestiona los valores y campos del formulario |
| Controller | Componente que conecta un input con el formulario |
| handleSubmit | Función que valida y envía los datos |
| Validación | Comprobacion de que los datos cumplen las reglas |
| Zod | Librería de esquemas de validación para JavaScript/TypeScript |
| Esquema | Definición de la forma y reglas de un objeto de datos |
| Resolver | Integración que traduce el esquema Zod al formulario |
| zodResolver | Resolver oficial de React Hook Form para Zod |
| formState | Estado del formulario: errores, envío, dirty |
| errors | Objeto con los errores por campo |
| Regex | Expresion regular para validar formatos como el teléfono |
| reset | Función que limpia los valores del formulario |
