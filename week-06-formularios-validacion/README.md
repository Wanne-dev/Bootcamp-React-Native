# Semana 06: Formularios y Validación

- Ruta: `bootcamp/week-06-formularios-validacion/`
- Dominio de práctica: Papelería Digital (datos del cliente y del pedido)

## Descripción

Se construye el formulario de datos del pedido (nombre, contacto, dirección de entrega) con React Hook Form y se valida con Zod antes del checkout.

## Objetivos

- Crear formularios con React Hook Form.
- Validar datos con esquemas de Zod.
- Mostrar errores por campo y enviar datos validos.

## Entregables

1. Formulario de datos del cliente con validación.
2. Esquema Zod integrado al formulario.

## Checklist de entrega

- [ ] El formulario captura nombre, teléfono y dirección.
- [ ] Los campos se validan con reglas de Zod.
- [ ] Los errores se muestran junto al campo.
- [ ] El envío solo ocurre con datos validos.
