# Práctica 01 - Formulario con React Hook Form

## Objetivo

Crear el formulario de datos del cliente usando `useForm` y `Controller`.

## Paso a paso

1. Instalar `react-hook-form`.

2. Crear `FormularioPedido` con tres campos: nombre, teléfono y dirección.

3. Usar `Controller` para conectar cada `TextInput`.

4. Agregar un botón que llame `handleSubmit(enviar)` y registre los datos en consola.

## Criterios de cumplimiento

- [ ] No hay `useState` por campo.
- [ ] Los tres campos usan `Controller`.
- [ ] El botón invoca `handleSubmit`.
