# Semana 09: Animaciones Basicas

- Ruta: `bootcamp/week-09-animaciones-basicas/`
- Dominio de práctica: Papelería Digital (feedback visual del carrito)

## Descripción

Se animan elementos clave de la interfaz con la API Animated de React Native: transiciones al abrir el detalle y feedback al agregar productos al carrito.

## Objetivos

- Usar `Animated.Value` y `Animated.timing`.
- Animar opacidad, escala y transformaciones.
- Integrar animaciones en la UI sin romper la usabilidad.

## Entregables

1. Animación al agregar un producto al carrito.
2. Transición de entrada de la tarjeta de producto.

## Checklist de entrega

- [ ] El botón de agregar responde con una animación.
- [ ] Las tarjetas entran con fade al cargar.
- [ ] Las animaciones usan el driver nativo cuando es posible.
- [ ] La animación no bloquea la interacción.
