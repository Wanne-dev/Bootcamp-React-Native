# Glosario - Semana 09

| Término | Definición |
|---|---|
| Animated | API de React Native para crear animaciones |
| Animated.Value | Valor numérico animable |
| Animated.timing | Animación lineal entre valores con duración fija |
| Animated.spring | Animación con física de resorte |
| Animated.sequence | Reproduce animaciones una tras otra |
| Animated.parallel | Reproduce animaciones al mismo tiempo |
| interpolate | Mapea un rango de valores a otro rango |
| useNativeDriver | Ejecuta la animación en el hilo nativo |
| Opacidad | Transparencia de un elemento |
| Escala | Tamaño relativo de un elemento |
| Transform | Conjunto de transformaciones (escala, rotación, traslación) |
| Feedback visual | Respuesta animada a una acción del usuario |
| Duration | Duración de una animación en milisegundos |
