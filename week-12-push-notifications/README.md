# Semana 12: Push Notifications

- Ruta: `bootcamp/week-12-push-notifications/`
- Dominio de práctica: Papelería Digital (aviso de pedido listo)

## Descripción

Se configuran notificaciones para avisar al cliente cuando su pedido está listo para recoger, con permisos y manejo del token de dispositivo.

## Objetivos

- Configurar notificaciones locales con Expo.
- Solicitar permisos y obtener el token del dispositivo.
- Disparar una notificación ante un evento del negocio.

## Entregables

1. Notificación local de prueba.
2. Aviso "Tu pedido está listo" al confirmar la compra.
