# Glosario - Semana 12

| Término | Definición |
|---|---|
| Push notification | Mensaje que se muestra en el dispositivo aunque la app este cerrada |
| Notificación local | Notificación que dispara la propia app, sin servidor |
| Notificación remota | Notificación enviada desde un servidor a un token |
| Token push | Identificador único del dispositivo para recibir pushes |
| Permiso de notificaciones | Autorización del usuario para recibir avisos |
| Handler | Configuración de como se muestra la notificación en primer plano |
| expo-notifications | Módulo de Expo para gestionar notificaciones |
| expo-device | Módulo de Expo para obtener información del dispositivo |
| Badge | Contador numérico sobre el icono de la app |
| Trigger | Condición que dispara una notificación (inmediata o programada) |
| scheduleNotificationAsync | Método para programar una notificación |
