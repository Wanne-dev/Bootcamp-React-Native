# Proyecto Semana 12 - Notificaciones del pedido

## Objetivo

Integrar las notificaciones en el flujo de compra de la papelería.

## Estructura de archivos

```text
HolaMundo/
|-- src/
|   |-- notifications/
|   |   |-- config.js         // handler y permisos
|   |   |-- avisos.js         // avisoPedidoListo
|   |-- screens/
|   |   |-- ConfirmacionPedido.jsx
```

## Criterios de éxito

- [ ] Al confirmar un pedido, la app avisa con una notificación.
- [ ] El tap sobre la notificación lleva al contexto del pedido.
- [ ] El token se guarda para una futura integración remota.
- [ ] El permiso se pide en el momento adecuado.
